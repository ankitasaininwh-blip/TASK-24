# ReactJS Hello World

## Project Description
This project is created as part of TuteDude's MERN Stack course assignment. It demonstrates a basic ReactJS application that displays "Hello, World!" on the screen.

## Technologies Used
- HTML5
- React.js
- JavaScript
- Node.js
- Vite
- npm

## Features
- Simple ReactJS application
- Displays a "Hello, World!" heading
- Uses React components
- Built with Vite for development and production builds

```text
├── index.html

    ├── App.jsx

```

## How to Run Locally
1. Install Node.js.
2. Clone or download this repository.
3. Open the project folder in VS Code.
4. Install dependencies:
   ```bash
   npm install
   ```
5. Start the development server:
   ```bash
   npm run dev
   ```
6. Open the local URL shown in the terminal.

## Build for Production
Run the following command:
```bash
npm run build
```

The production-ready files will be generated in the `dist` folder.
